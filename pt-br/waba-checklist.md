Antes de conectar um número à API oficial do WhatsApp (WABA) no Ticketz PRO, verifique os itens abaixo. Cada etapa evita bloqueios ou reprovações durante a configuração na Meta.

## Acesso ao número que será conectado

Durante a ativação a Meta envia um SMS ou faz uma ligação com o código de verificação para o número que será conectado.

Se você usar a **coexistência** — manter o WhatsApp no celular enquanto usa a API —, também será necessário ter o aparelho com o aplicativo instalado e acesso imediato a ele.

## Acesso ao Facebook

A Meta cria um **Portfólio de Negócios** vinculado a uma conta pessoal do Facebook. Essa conta deve atender aos requisitos do Facebook:

- Nome real e data de nascimento verdadeiros.
- Informações pessoais consistentes com os documentos.
- Recomendamos acessar [facebook.com/id](https://facebook.com/id) e enviar a documentação pessoal **antes** de iniciar o processo.

O Portfólio de Negócios (também chamado de **BM**) é acessado em [business.facebook.com](https://business.facebook.com).

Se a empresa já tiver um Portfólio criado, qualquer conta do Facebook com acesso a ele poderá usá-lo. Para adicionar outras pessoas, vá até a tela inicial do Portfólio e escolha **Usuários → Pessoas**.

## Site empresarial

A verificação da empresa exige um site institucional com os dados comerciais completos.

Para empresas brasileiras, a página inicial deve conter:

- CNPJ
- Razão Social

## Cartão de crédito

Para enviar **mensagens de modelo** em conversas iniciadas pela empresa, é necessário cadastrar um cartão de crédito na configuração da conexão com o WhatsApp.

## Documentação da empresa e do responsável

Em alguns casos a validação da empresa por telefone não é possível. Nesses cenários, tenha em mãos:

- Contrato social ou outro documento de registro da empresa.
- Documento de identidade do responsável legal (por exemplo, CNH ou RG).

## Uso da API Cloud sem coexistência

Se você for usar a **API Cloud completa sem coexistência**, é necessário liberar o número do WhatsApp no aparelho antes de ativar a conexão. A forma mais direta é apagar a conta do aplicativo: vá em **Configurações → Conta → Apagar conta**.

Apagar a conta **remove todo o histórico e contatos** vinculados a ela. Se quiser preservar os dados, uma alternativa é alterar o número da conta no WhatsApp para outro número disponível, liberando assim o número atual para uso na API Cloud.

Essa etapa evita conflitos entre a sessão do aplicativo e o número registrado na API oficial.
