Before connecting a number to the official WhatsApp Business API (WABA) in Ticketz PRO, review the checklist below. Completing each item prevents blocks or rejections during the Meta setup.

## Access to the number to be connected

During activation, Meta sends an SMS or places a verification call to the number being connected.

If you use **coexistence** — keeping WhatsApp on the phone while using the API — you will also need the device with the app installed and immediate access to it.

## Facebook access

Meta creates a **Business Portfolio** tied to a personal Facebook account. That account must meet Facebook requirements:

- Real name and accurate date of birth.
- Personal information consistent with your documents.
- We recommend visiting [facebook.com/id](https://facebook.com/id) and submitting personal identification **before** starting the process.

The Business Portfolio (also called **BM**) is accessed at [business.facebook.com](https://business.facebook.com).

If the company already has a Business Portfolio, any Facebook account with access to it can be used. To add other people, go to the Portfolio home screen and choose **Users → People**.

## Business website

Company verification requires a corporate website with complete business details.

For Brazilian companies, the homepage must display:

- CNPJ
- Company legal name (Razão Social)

## Credit card

To send **template messages** in conversations started by the business, you must add a credit card to the WhatsApp connection settings.

## Company and representative documentation

In some cases phone validation is not possible. In those scenarios, keep the following available:

- Articles of incorporation or equivalent company registration document.
- Government-issued ID of the legal representative (for example, driver's license or national ID).

## Using the Cloud API without coexistence

If you are using the **full Cloud API without coexistence**, you must release the WhatsApp number from the device before activating the connection. The most direct way is to erase the account in the app: go to **Settings → Account → Erase account**.

Erasing the account **deletes all chat history and contacts** tied to it. If you want to keep that data, an alternative is to change the WhatsApp account number to another available number, which releases the current number for use with the Cloud API.

This prevents conflicts between the app session and the number registered on the official API.
